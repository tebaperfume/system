================================================
PRIZE24 — نظام الموافقات | دليل التشغيل خطوة بخطوة
================================================

الملفات:
  index.html        → صفحة اللعبة (تديها للناس)
  admin.html        → لوحة التحكم بتاعتك (متديهااش لحد)
  api/register.js   → تسجيل وفحص حالة الإيدي
  api/admin.js      → قائمة الإيديهات + قبول/رفض

------------------------------------------------
الخطوة 1: قاعدة البيانات المجانية (Upstash)
------------------------------------------------
1. ادخل upstash.com واعمل حساب مجاني (بالجوجل أسهل).
2. من Console → Redis → Create Database (اختر أي Region والخطة Free).
3. افتح قاعدة البيانات وانسخ منها:
   - REST URL      (شبه: https://xxx-xxx.upstash.io)
   - REST TOKEN    (طويل، ابدا بـ AAAA)

------------------------------------------------
الخطوة 2: النشر على Vercel
------------------------------------------------
1. نزل Node.js من nodejs.org وثبته.
2. افترمينال/كماند في فولدر المشروع واكتب:
      npm install -g vercel
      vercel
3. هيسألك تسجل دخول (اعمل بحساب جوجل) واسم المشروع — اكتب أي اسم.
4. بعد ما يخلص هيديك رابط (شبه: https://prize24-xxxx.vercel.app)

------------------------------------------------
الخطوة 3: المتغيرات السرية
------------------------------------------------
1. افتح vercel.com → مشروعك → Settings → Environment Variables.
2. ضيف 3 متغيرات:
   UPSTASH_REDIS_REST_URL   = اللينك اللي نسخته من Upstash
   UPSTASH_REDIS_REST_TOKEN = التوكن اللي نسخته من Upstash
   ADMIN_SECRET             = أي باسورد انت تحبه (ده باسورد لوحة التحكم)
3. ارجع للترمينال واكتب:
      vercel --prod
   عشان يبعت النسخة الجديدة بالمتغيرات.

------------------------------------------------
الخطوة 4: ربط الصفحات
------------------------------------------------
1. افتح index.html وابحث عن:  YOUR-PROJECT.vercel.app
   وحط مكانه رابط مشروعك الحقيقي واحفظ.
2. ارفع index.html ده أي مكان (تليجرام/استضافة/موقع).
3. لوحة التحكم: افتح  https://رابط-مشروعك.vercel.app/admin.html
   - اكتب رابط المشروع و ADMIN_SECRET
   - هيظهرلك كل الإيديهات: ✔ قبول  ✖ رفض  🗑 حذف

------------------------------------------------
إزاي الدنيا بتشتغل؟
------------------------------------------------
- أول مرة حد يدخل بإيدي جديد  → يتسجل "pending" + يوصلك تنبيه تليجرام
  والمستخدم يشوف: "انتظر حتى تتم الموافقة من المطور"
- لو حاول يدخل تاني قبل الموافقة → نفس الرسالة، ميدخلش
- توافق من اللوحة          → يدخل عادي (نفس اللوجين القديم)
- ترفض                    → يشوف "تم رفض طلبك"
- التليجرام القدير + رفع الصورة + كل حاجة تانية شغالة زي ما هي
